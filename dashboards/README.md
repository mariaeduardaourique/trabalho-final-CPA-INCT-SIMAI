Como rodar os dashboards:

1. pip install streamlit
2. streamlit run (nome do arquivo).py
3. abrir a URL local

Ou, pode acessar as URLs globais:
INCT  -   https://dados-inct-dashboard.streamlit.app/
UFRGS -   https://dados-base-externa-ufrgs-dashboard.streamlit.app/
MUP   -   https://dados-muprs-dashboard.streamlit.app/
