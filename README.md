### Base de dados geográficos — UFRGS

Este projeto utiliza o arquivo `cheias_rhguaiba_2024_db_v12.gpkg`, disponibilizado publicamente no Zenodo.

**Fonte:** https://zenodo.org/records/13227745

O arquivo original não foi incluído diretamente no repositório devido ao seu tamanho (aproximadamente 187 MB).

**Para reproduzir o processamento:**

1. Acesse o link da fonte original.
2. Baixe o arquivo `cheias_rhguaiba_2024_db_v12.gpkg`.
3. Coloque-o na pasta `dados/originais/` do projeto.
4. Execute o notebook `scripts/fonteexterna.ipynb`.

Os arquivos CSV processados, o GeoPackage reduzido e os gráficos gerados estão disponíveis no repositório para consulta, sem a necessidade de baixar a base original.
